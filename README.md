# claude-rout

Desktop-окно для **настоящего Claude Code**. Внутри работает тот же `claude.exe`, что и в
терминале, со скиллами, памятью, `CLAUDE.md`, субагентами и правами на инструменты. Окно
показывает это как чат-приложение: список чатов, история, потоковый ответ, карточки
инструментов, запросы прав, встроенный браузер.

Модель можно брать двумя путями:
- **подписка** — обычный вход Claude Code;
- **мост** — любой Anthropic-совместимый прокси (`ANTHROPIC_BASE_URL`), например к стороннему
  провайдеру API. Мост — отдельный локальный проект и в этот репозиторий не входит.

Electron + Node.js, интерфейс без фреймворков. Собрано вместе с Claude Code.

## Что умеет

- **Чаты.** Новый чат спрашивает папку проекта — по ней Claude Code берёт `CLAUDE.md` и память.
  Поиск, переименование, удаление из списка.
- **История без своей базы.** Транскрипты пишет сам Claude Code в `~/.claude/projects/`, окно
  их читает. Закрыли приложение, открыли завтра — чат продолжается (`--resume`).
- **Права.** «Спрашивать» (карточка: Разрешить / Разрешить на сессию / Отклонить),
  «Правки без вопросов», «Только план», «Всё без вопросов».
- **Движок и модель на каждый чат.** Подписка или мост; модель из каталога моста с множителем цены.
- **Опросник.** Вопросы `AskUserQuestion` приходят формой (радио, чекбоксы, «Другое»).
- **Встроенный браузер.** Панель справа; для Claude это MCP-сервер `browser`
  (`navigate / screenshot / text / click / type / eval / console / resize / scroll / back`),
  скриншоты приходят модели картинкой.
- **Размышления** — свёрнутым блоком, **картинки** в ответах и результатах инструментов.
- **Строка состояния хода** с секундомером: отправлено → модель отвечает → выполняет
  инструмент → ждёт модель. Если модель молчит дольше 25 с — строка говорит об этом прямо.
  Ошибка процесса или пустой ответ — заметка с кнопкой «Попробовать снова».
- Esc — прервать ход, Ctrl+N — новый чат, переключатель темы.

## Устройство

```
electron/main.mjs      — окно Electron, сервер поднимается внутри процесса
electron/browser.mjs   — панель встроенного браузера (WebContentsView)
server/index.mjs       — HTTP + WebSocket, список чатов, процессы, автоподъём моста
server/claude.mjs      — обёртка над claude.exe: stream-json туда и обратно, права по stdio
server/history.mjs     — чтение транскриптов ~/.claude/projects
server/mcp-browser.mjs — MCP-сервер, через который Claude управляет браузером
public/                — index.html, app.js, style.css
```

Один процесс Claude Code на открытый чат:

```
claude.exe -p --input-format stream-json --output-format stream-json
  --include-partial-messages --permission-prompt-tool stdio
  --permission-mode <режим> [--resume <id>] --mcp-config data/mcp.json
```

Процесс живёт, пока чат открыт и не простаивает `idleKillMinutes`; следующий ход поднимает
его заново с `--resume`. Переменные моста (`ANTHROPIC_BASE_URL` и т. д.) ставятся только
процессу Claude, не всей системе.

## Запуск

Нужны Node.js 20+ и установленный Claude Code.

```bash
npm install
mkdir data
cp config.example.json data/config.json   # по желанию: порт, движок, путь к claude.exe
npm run app                                # окно
npm start                                  # без окна: http://127.0.0.1:5179
```

Трассировка событий процесса: `CLAUDE_ROUT_TRACE=1 npm start`.

## Ограничения

- Через мост нет кэша промпта: каждый ход отправляет весь контекст заново, длинные сессии дороже.
- Служебные запросы Claude Code (заголовки и т. п.) идут на «малую» модель моста.
- Сервер слушает только `127.0.0.1`.
- Проверялось на Windows 11.
